Inter-Variable.woff2
--------------------
Variable weight (100–900) Latin subset of the Inter typeface, extracted from
the @fontsource-variable/inter npm package.

Inter is licensed under the SIL Open Font License 1.1, which permits
bundling and redistribution — see https://openfontlicense.org.

Self-hosted here (instead of next/font/google) so `next build` never
depends on reaching fonts.googleapis.com. If you ever want a different
weight range or the italic style, reinstall the package and copy the
relevant file from node_modules/@fontsource-variable/inter/files/.
